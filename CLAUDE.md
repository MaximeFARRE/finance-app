## Commits Git

Commiter **fréquemment** — une unité logique = un commit. Ne jamais attendre la fin d'une tâche entière.
- Maximum 3-4 fichiers par commit
- Commiter après chaque composant, type, test ou config créé/modifié
- Conventional Commits : `feat:`, `fix:`, `chore:`, `docs:`, `test:`, `refactor:`
